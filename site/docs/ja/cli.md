# CLI ビューアー

```bash
npx react-llm-markdown README.md
```

Markdown ファイルを Web レンダラーでレンダリングしてブラウザで開き、保存するたびに再読み込みします。ディスクに保存したモデルの出力を読んだり、
プロジェクトのドキュメントをダイアグラムやチャートが描画された状態で読んだりするのに便利です。

## 使い方

```bash
react-llm-markdown [file.md | folder] [options]
```

| | |
|---|---|
| `file.md` | 開くファイル。 |
| `folder` | その `README.md`（または `readme.md`、`README.markdown`、`index.md`）を開きます。デフォルト：現在のフォルダー。 |
| `-p, --port <n>` | 待ち受けるポート。デフォルト：空いているポート。 |
| `--no-open` | ブラウザを開く代わりに URL を表示します。 |
| `-v, --version` | バージョンを表示します。 |
| `-h, --help` | ヘルプを表示します。 |

同じフォルダー内の他の `.md` ファイルへのリンクもビューアーで開き、相対パスの画像も読み込まれます。ライトとダークは
上部バーのボタンで切り替えられます。

## 安全性

- `127.0.0.1` のみで待ち受け、`127.0.0.1` または `localhost` 宛てのリクエストにのみ応答します（そのため Web ページが
  DNS リバインディングを通じてアクセスすることはできません）。
- ドキュメントのフォルダー内のファイルのみを配信します。`..`、フォルダー外を指すシンボリックリンク、`.env` のようなドットファイルは決して配信しません。
- ライブラリと同じサニタイザーでレンダリングするため、ファイル内の HTML やリンクがスクリプトを実行することはできません。

Node.js 20 以降が必要です。CLI はオプションの peer を一切必要としないため、`npx` だけで十分です。
