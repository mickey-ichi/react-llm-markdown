# はじめに

**react-llm-markdown** は、言語モデルが書いた Markdown を、Web の React と React Native でレンダリングします。
モデルが好んで使うリッチなブロックに対応しつつ、そのテキストにコードを実行させることはありません。

モデルの回答は信頼できない入力です。プロンプトインジェクションによって、スクリプトを実行したり、外部と通信したり、
読み手を欺いたりするように作られた HTML、リンク、ダイアグラム、チャートのオプションを返させることができます。
このライブラリはそれらすべてをレンダリングし、それ以外のものを無害化します。

## 得られるもの

- **リッチなブロック**：GFM のテーブル・タスクリスト・脚注、シンタックスハイライト（Shiki）、数式（KaTeX）、Mermaid のダイアグラム、
  JSON のフェンスから描く ECharts のチャート、CJK に対応した強調。
- **ストリーミング**：回答がストリーミングされている間、書きかけの Markdown が補修されるため、テーブルやコードフェンスがレイアウトを崩すことはなく、
  `**` が画面にちらつくこともありません。
- **LLM のクセに対応**：`\( … \)` / `\[ … \]` の数式、1 つの改行を改行として扱います。
- **デフォルトで堅牢**：サニタイズされた HTML、URL の許可リスト、制限をかけた Mermaid と KaTeX、チャートのオプションに対する許可リストと上限。
  すべてのレンダラーで 27 種類の攻撃ペイロードを使ってテストしています。
- **1 つのパッケージで Web とネイティブの両方に対応**し、同じパーサーとセキュリティポリシーを共有します。

## 3 つのエントリーポイント

| インポート | 用途 |
|---|---|
| `react-llm-markdown`（または `/web`） | Web 上の React。[Streamdown](https://streamdown.ai) をベースにしています |
| `react-llm-markdown/native` | React Native と Expo：ネイティブビュー、数式・Mermaid・チャートには WebView |
| `react-llm-markdown/core` | 両者が共有する DOM 非依存の部分：パース、ストリーミング中の補修、セキュリティポリシー |

React Native では、`import … from 'react-llm-markdown'` は自動的にネイティブのエントリーに解決されます。

任意の `.md` ファイルをブラウザで開き、ライブリロードで表示する CLI もあります。

```bash
npx react-llm-markdown README.md
```
